# Type 2 Diabetes Analysis & Prediction (PySpark, Databricks)

## Описание проекта

В рамках проекта был проведён анализ и моделирование данных по развитию диабета 2 типа на основе датасета (50 лет наблюдений).

Датасет содержит информацию о 10 000 пациентах и включает:
- клинические показатели (glucose, HbA1c, BMI)
- факторы образа жизни
- временную динамику заболевания

---

## Цель проекта

- провести исследовательский анализ данных (EDA)
- выявить ключевые факторы риска
- проанализировать динамику заболевания (cohort analysis)
- построить модель для предсказания развития диабета

---

## Стек

- Python  
- PySpark  
- Databricks  
- Spark ML
- Matplotlib

## Данные

- Количество строк: 496 362 
- Количество пациентов: 10 000  
- Период наблюдений: 1976–2026

### Целевая переменная

`future_diabetes_5yr`:
- 0 → диабет не развивается в течение 5 лет  
- 1 → диабет развивается  

Распределение классов:
- 0: 246 330  
- 1: 250 032  

-> датасет сбалансирован

---

## 🔍 Основные инсайты (EDA)

Средние значения по датасету:
- BMI: ~26  
- Glucose: ~112  
- HbA1c: ~5.46  

Сравнение групп:

- Без диабета:
  - BMI: ~22.1  
  - Glucose: ~84.8  
  - HbA1c: ~4.56  

- С диабетом:
  - BMI: ~29.9  
  - Glucose: ~138.5  
  - HbA1c: ~6.34  

-> пациенты с диабетом имеют значительно более высокие метаболические показатели  

Физическая активность:
- low -> риск ~0.77  
- medium -> ~0.49  
- high -> ~0.018  

-> низкая физическая активность существенно увеличивает риск  

Возраст:
- минимальный: 19 лет  
- основная масса: 35–70 лет  

-> датасет смещён в сторону более взрослой популяции  

Корреляции:
- BMI ≈ 0.64  
- glucose ≈ 0.70  
- HbA1c ≈ 0.65  

-> метаболические показатели имеют устойчивую связь с развитием диабета  

---

## 📊 Cohort Analysis

- наблюдается снижение retention rate со временем  
- ранние когорты имеют более длинную историю наблюдений  
- поздние когорты ограничены временным окном данных  

-> наблюдается типичное поведение cohort decay  

---

## Модель

Использована модель:
- Logistic Regression (Spark ML)

Качество модели:
- ROC-AUC: **~0.96**

-> модель хорошо разделяет классы  

### Интерпретация признаков

Наибольшее влияние:
- fasting_glucose (~1.90)  
- metabolic_risk_score (~1.86)  
- BMI (~1.26)  

-> увеличение этих показателей повышает риск  

Умеренное влияние:
- HbA1c (~0.78)  
- age (~0.58)  

Отрицательное влияние:
- lifestyle_score (~ -0.15)  

-> более здоровый образ жизни снижает риск
